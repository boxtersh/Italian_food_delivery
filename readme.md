# Italian Food Delivery — Документация проекта

Веб-приложение для доставки итальянской еды на **FastAPI** с разделением ролей (клиент / администратор), каталогом блюд, корзиной и системой заказов.

## 📝 Описание модулей

| Файл / папка | Роль |
|--------------|------|
| `run.py` | Запускает сервер: `uvicorn app:app --reload` |
| `app.py` | Создаёт приложение FastAPI, подключает все роутеры и статику |
| `config.py` | Читает настройки из `.env` (URL БД, секретный ключ JWT, и др.) |
| `database.py` | Настройка SQLAlchemy: `engine`, `SessionLocal`, `Base`, `get_db()` |
| `auth.py` | Хеширование паролей, создание/проверка JWT, зависимости `get_current_user` / `get_current_admin` |
| `models.py` | ORM-модели: `User`, `Dish`, `CartItem`, `Order`, `OrderItem` |
| `schemas.py` | Pydantic-схемы для валидации входящих данных и сериализации ответов |
| `routers/auth.py` | Эндпоинты регистрации и входа (выдача токена) |
| `routers/client/` | Эндпоинты для покупателей: просмотр меню по категориям, корзина, оформление заказов |
| `routers/admin/` | Эндпоинты для администратора: CRUD блюд по категориям, управление статусами заказов |
| `templates/index.html` | Шаблон главной страницы |
| `static/style.css` | Стили интерфейса |
| `static/app.js` | Клиентская логика (запросы к API) |

### 🔀 Логика разделения ролей

| Роль | Доступ |
|------|--------|
| **Клиент** | Просмотр меню, добавление в корзину, оформление и отслеживание своих заказов |
| **Админ** | Добавление / редактирование / удаление блюд, управление статусами всех заказов |

> Защита эндпоинтов реализуется через зависимости FastAPI:
> - `Depends(get_current_user)` — только авторизованные
> - `Depends(get_current_admin)` — только администраторы
> - `Depends(get_optional_user)` — гости
### 🗃 Категории блюд / статусы

Все категории хранятся в **одной таблице `dishes`** и различаются полем `category` (enum `DishCategory`):

```
PIZZA · PASTA · SALAD · DESSERT · DRINK
```

Все статусы хранятся в **одной таблице `Order`** и различаются полем `status` (enum `OrderStatus`):

```
CONFIRMED · DELIVERING · COMPLETED · CANCELLED
```

## ▶️ Запуск проекта

```
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Настроить переменные окружения в .env
#    DATABASE_URL=...
#    SECRET_KEY=...

# 3. Запустить сервер
python run.py
```

После запуска API доступно по адресу:
- **Приложение:** http://localhost:8000
- **Swagger-документация:** http://localhost:8000/docs
